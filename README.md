## 代码生成工具

CRPC 提供了两个代码生成工具，用于自动生成客户端和服务端代码：

- **gencrpcserverv3** - 生成服务端代码（处理网络请求的分发逻辑）
- **gencrpcclientv3** - 生成客户端代码（提供类型安全的调用接口）

### 安装工具

```bash
go install github.com/ndsky1003/crpc/v3/cmd/gencrpcserverv3@latest
go install github.com/ndsky1003/crpc/v3/cmd/gencrpcclientv3@latest
```

### 使用方式

#### 1. gencrpcserverv3 - 服务端代码生成

生成服务端的 `HandleMsg` 方法，用于分发 RPC 请求到对应的结构体方法。

**基本用法：**
```bash
gencrpcserverv3 [flags]
```

**参数说明：**
- `-f` : 源文件路径（默认当前目录下的 `.go` 文件）
- `-s` : 生成文件的后缀（默认 `_crpc_server_gen`）
- `-o` : 输出文件名（可选）
- `-out_dir` : 输出目录（可选）

**在代码中使用：**
```go
//go:generate gencrpcserverv3
package main

type MyService struct{}

func (s *MyService) Method1(ctx context.Context, req *Req) (*Res, error) {
    return &Res{Msg: "OK"}, nil
}

func (s *MyService) Method2(req *Req) error {
    return nil
}
```

运行 `go generate ./...` 后，会生成 `my_service_crpc_server_gen.go` 文件，包含 `HandleMsg` 方法。

#### 2. gencrpcclientv3 - 客户端代码生成

生成客户端的调用接口，提供类型安全的方法调用。

**基本用法：**
```bash
gencrpcclientv3 [flags]
```

**参数说明：**
- `-f` : 源文件路径（默认当前目录下的 `.go` 文件）
- `-out_dir` : 输出目录（必选）
- `-o` : 输出文件名（可选，默认为 `原文件名_client_gen.go`）
- `-package` : 生成的包名（默认与源文件相同）
- `-client` : 生成的代码内部使用的全局 Client 变量名（默认 `DefaultClient`）
- `-service` : 全局默认 Service Name（默认为结构体名）
- `-module` : 全局默认 Module Name（默认为 Service Name）

**在代码中使用：**
```go
//go:generate gencrpcserverv3
//go:generate gencrpcclientv3 --out_dir=./client --package=client --client=MyClient --service=MyService --module=MyModule
package main

type MyService struct{}

func (s *MyService) GetUser(ctx context.Context, req *GetUserReq) (*GetUserRes, error) {
    return &GetUserRes{Name: "John"}, nil
}
```

运行 `go generate ./...` 后，会在 `./client` 目录生成客户端代码。

### 完整示例

#### 服务端文件 `service.go`:
```go
//go:generate gencrpcserverv3
//go:generate gencrpcclientv3 --out_dir=../client --package=client --client=GameClient --service=GameService --module=game
package main

import (
    "context"
    "github.com/example/project/dto"
)

type GameService struct{}

// @crpc:CallType:Call,Send,Go
func (s *GameService) GetPlayerInfo(ctx context.Context, meta *dto.Meta, req *dto.GetPlayerReq) (*dto.GetPlayerRes, error) {
    return &dto.GetPlayerRes{
        ID:    req.PlayerID,
        Name:  "Player_" + req.PlayerID,
        Level: 100,
    }, nil
}

func (s *GameService) UpdatePlayerName(ctx context.Context, req *dto.UpdateNameReq) error {
    // 更新玩家名称逻辑
    return nil
}
```

#### 生成的客户端代码 `client/game_service_client_gen.go`:
```go
// Code generated by gencrpcclientv3. DO NOT EDIT.
package client

import (
    "context"
    "github.com/ndsky1003/crpc/v3/client"
    "github.com/example/project/dto"
)

var GameClient *client.Client

func init() {
    // 初始化客户端连接
    GameClient = client.Dial(context.Background(), "GameService", ":8080")
}

// GetPlayerInfo 调用 GetPlayerInfo 方法
// @crpc:CallType:Call,Send,Go
func GetPlayerInfo(ctx context.Context, meta *dto.Meta, req *dto.GetPlayerReq, opts ...*client.Option) (*dto.GetPlayerRes, error) {
    // Meta 处理 (放入 opts)
    opts = append(opts, client.Options().SetMeta(meta))

    // Req 处理
    var reqBody any = req

    // Call 模式：同步等待
    var res dto.GetPlayerRes
    var resPtr any = &res

    err := GameClient.Call(ctx, "game", "GetPlayerInfo", reqBody, resPtr, opts...)
    return &res, err
}

// UpdatePlayerName 调用 UpdatePlayerName 方法（无 meta）
func UpdatePlayerName(ctx context.Context, req *dto.UpdateNameReq, opts ...*client.Option) error {
    // Req 处理
    var reqBody any = req

    // Call 模式：同步等待
    var resPtr any = nil

    err := GameClient.Call(ctx, "game", "UpdatePlayerName", reqBody, resPtr, opts...)
    return err
}
```

### 注解支持

客户端代码生成支持以下注解：

```go
// @crpc:CallType:Call,Send,Go    // 生成 Call、Send、Go 三种调用方法
// @crpc:Client: CustomClient     // 使用指定的客户端变量
// @crpc:Service: CustomService   // 使用指定的服务名
// @crpc:Module: custom_module    // 使用指定的模块名
// @crpc:FuncName: CustomName     // 生成的方法名
// @crpc:IsSkip:true              // 跳过生成此方法
```

### 开发流程

1. **定义服务结构体和方法**
   ```go
   // 在 .go 文件中定义服务
   type UserService struct{}

   func (s *UserService) CreateUser(ctx context.Context, req *CreateUserReq) (*CreateUserRes, error) {
       // 实现逻辑
   }
   ```

2. **添加 generate 指令**
   ```go
   //go:generate gencrpcserverv3
   //go:generate gencrpcclientv3 --out_dir=../client --package=client
   ```

3. **生成代码**
   ```bash
   go generate ./...
   ```

4. **使用生成的代码**
   ```go
   // 服务端注册
   server, _ := crpc.NewServer(context.Background())
   server.Listen(":8080")

   // 客户端调用
   res, err := client.CreateUser(ctx, &CreateUserReq{Name: "John"})
   ```

### CRPC 方法签名完整规范

#### 参数规则
- **Context** (`context.Context`) - 可选，必须是第一个参数
- **Meta** - 必须和 Request 一起出现（单独存在时会被当作 Request）
- **Request** - 必需的参数（当只有一个非 Context 参数时）

> 重要：当只有一个参数（除了 Context）时，它会被当作 `request`，而不是 `meta`。`meta` 必须和 `request` 一起出现。

#### 支持的参数组合（6 种）
1. **()** - 无参数
2. **(ctx)** - 只有 Context
3. **(req)** - 只有 Request
4. **(ctx, req)** - Context + Request
5. **(meta, req)** - Meta + Request
6. **(ctx, meta, req)** - Context + Meta + Request

#### 支持的返回值组合（4 种）
1. **()** - 无返回值
2. **(res)** - 只有 Response
3. **(error)** - 只有 Error
4. **(res, error)** - Response + Error（标准返回）

### 函数签名完整规范

函数支持与结构体方法完全相同的签名组合。以下是使用 `RegisterFunc` 注册的函数示例：

```golang
// -------------------------------------------------------
// 无参数组合
// -------------------------------------------------------
func FnEmpty() {}                                                        // () -> ()
func FnNoParamsRes() *dto.Res {                                          // () -> (res)
    return &dto.Res{Msg: "OK from FnNoParamsRes"}
}
func FnNoParamsErr() error {                                             // () -> (error)
    return nil
}
func FnNoParamsResErr() (*dto.Res, error) {                              // () -> (res, error)
    return &dto.Res{Msg: "OK from FnNoParamsResErr"}, nil
}

// -------------------------------------------------------
// 只有 Context
// -------------------------------------------------------
func FnCtxOnly(ctx context.Context) {}                                   // (ctx) -> ()
func FnCtxOnlyRes(ctx context.Context) *dto.Res {                        // (ctx) -> (res)
    return &dto.Res{Msg: "OK from FnCtxOnlyRes"}
}
func FnCtxOnlyErr(ctx context.Context) error {                           // (ctx) -> (error)
    return nil
}
func FnCtxOnlyResErr(ctx context.Context) (*dto.Res, error) {            // (ctx) -> (res, error)
    return &dto.Res{Msg: "OK from FnCtxOnlyResErr"}, nil
}

// -------------------------------------------------------
// 只有 Request
// -------------------------------------------------------
func FnReqOnly(req *dto.Req) (*dto.Res, error) {                         // (req) -> (res, error)
    return &dto.Res{Msg: "OK from FnReqOnly"}, nil
}
func FnResOnly(req *dto.Req) *dto.Res {                                  // (req) -> (res)
    return &dto.Res{Msg: "OK from FnResOnly"}
}
func FnErrOnly(req *dto.Req) error {                                     // (req) -> (error)
    return nil
}
func FnNoReturn(req *dto.Req) {}                                         // (req) -> ()

// -------------------------------------------------------
// Context + Request
// -------------------------------------------------------
func FnCtxReqPtr(ctx context.Context, req *dto.Req) (*dto.Res, error) {  // (ctx, req) -> (res, error)
    return &dto.Res{Msg: "OK from FnCtxReqPtr"}, nil
}
func FnCtxReqVal(ctx context.Context, req string) (string, error) {      // (ctx, req) -> (res, error)
    return "FnCtxReqVal:" + req, nil
}

// -------------------------------------------------------
// Meta + Request（注意：这里第二个参数会被当作 req）
// -------------------------------------------------------
func FnMetaReq(meta *dto.Meta, req *dto.Req) (*dto.Res, error) {         // (meta, req) -> (res, error)
    return &dto.Res{Msg: "OK from FnMetaReq"}, nil
}

// -------------------------------------------------------
// Context + Meta + Request（完整3参数）
// -------------------------------------------------------
func FnCtxMetaReqResErr(ctx context.Context, meta *dto.Meta, req *dto.Req) (*dto.Res, error) { // (ctx, meta, req) -> (res, error)
    traceid := trace.GetTraceID(ctx)
    fmt.Printf("[FnCtxMetaReqResErr] Meta=%v, Req=%v, traceid=%v\n", meta, req, traceid)
    return &dto.Res{Msg: "OK from FnCtxMetaReqResErr"}, nil
}
func FnCtxMetaReqRes(ctx context.Context, meta *dto.Meta, req *dto.Req) *dto.Res {             // (ctx, meta, req) -> (res)
    return &dto.Res{Msg: "OK from FnCtxMetaReqRes"}
}
func FnCtxMetaReqErr(ctx context.Context, meta *dto.Meta, req *dto.Req) error {                // (ctx, meta, req) -> (error)
    return nil
}
func FnCtxMetaReq(ctx context.Context, meta *dto.Meta, req *dto.Req) {}                       // (ctx, meta, req) -> ()
```

### 注册函数示例

```golang
// 注册函数到客户端
client.RegisterFunc("MyModule", FnCtxReqPtr)                    // 使用函数名
client.RegisterFunc("MyModule", FnCtxReqVal, "CustomName")     // 自定义函数名

// 注册所有函数
functions := []any{
    FnEmpty, FnNoParamsRes, FnNoParamsErr, FnNoParamsResErr,
    FnCtxOnly, FnCtxOnlyRes, FnCtxOnlyErr, FnCtxOnlyResErr,
    FnReqOnly, FnResOnly, FnErrOnly, FnNoReturn,
    FnCtxReqPtr, FnCtxReqVal, FnMetaReq,
    FnCtxMetaReqResErr, FnCtxMetaReqRes, FnCtxMetaReqErr, FnCtxMetaReq,
}

for _, fn := range functions {
    if err := client.RegisterFunc("MyModule", fn); err != nil {
        log.Printf("Register function error: %v", err)
    }
}
```

> 注意：除了 **context.Context** 和 **error**，其他的参数和返回值均支持值类型与指针类型。
